# Vitrine de Jogos

Os 100 jogos mais famosos de PS5 e Xbox, com a nota da crítica (Metascore) e o preço de tabela na PlayStation Store e na Microsoft Store.

- Capas carregadas da Wikipédia; se alguma não carregar, aparece uma capa ilustrada.
- Preços em reais, de referência (out/2026). Cada preço abre a loja oficial com o valor do dia.

Para editar a lista, mude o array `RAW` no `index.html`.
